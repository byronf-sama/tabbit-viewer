# Getting started

This file lives in a subfolder. Its image and links are relative to `samples/guide/`.

![Small rabbit](rabbit-small.svg)

1. Open a file with **File > Open** (⌘O).
2. Press ⌘E to switch between View and Edit.
3. Press ⌘S to save.

Go back to the [welcome page](../welcome.md) or open the [sample HTML page](../page.html).
